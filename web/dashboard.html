Features

核心能力

从细则生成、批量批改到实时监控与导出，一条命令跑完整条阅卷链路。

AI 多模态评分

识别手写答题卡，基于评分细则逐采分点给分，输出理由与置信度。

细则锚定防幻觉

细则结构化落盘 + 版本号 + 锁定，批改中禁止 AI 重写，杜绝评分漂移。

Playwright 自动化

直接操作 DOM，不占鼠标键盘，浏览器可最小化，后台静默挂机批改。

实时监控面板

本地端口 + SSE 实时推送，进度、得分、异常一目了然，手机也可远程查看。

微信推送

开始 / 进度 / 异常 / 完成自动推送到微信（workbuddy 小龙虾等任意 webhook）。

历史与导出

批改记录全程留痕，一键导出 CSV / JSON / HTML，支持回查与统计。

评分细则锚定 —— 防幻觉的核心

1

生成细则

AI 分析题干，产出结构化采分点（分值 + 关键词）。

2

教师确认

导出独立 MD 供教师检查，确认后锁定 + 版本号。

3

落盘锚定

细则写入 data/rubrics/*.json，与对话流彻底解耦。

4

强制复用

每份答卷注入同一份锁定细则，禁止 AI 凭空造分。

规则清晰：对话负责「生成 + 确认」，文件负责「存储 + 锚定」，二者职责分离。

Architecture

四层架构

业务逻辑全部下沉到引擎层，CLI 与 Skill 只是薄封装。即使脱离 Agent，也能直接用命令行跑通。

监控层独立运行在本地端口，SSE 实时推送批改进度，不侵入阅卷主流程。
